这是我的个人网站源码，由纯静态 HTML + CSS + JavaScript 构建，托管于 GitHub Pages。

## 内容结构

- `index.html` —— 主页面（关于我、能力、实习经历、奖项表、作品展示、荣誉证书）
- `单双数游戏.html` —— 独立交互课件作品
- `images/compressed/` —— 已压缩的 WebP 图片资源（网页展示用）
- `images/证书-*.jpg|png` —— 荣誉证书原图（点击可查看大图）
- `videos/` —— 课件与课堂实录视频
